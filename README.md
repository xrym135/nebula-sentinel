## Features

- **Attack Graph** — Kill-chain stages with correlation confidence
- **Multi-Agent Workflow** — Threat · CVE · Forensics · Response agents
- **AI Threat Analysis** — Pattern detection and response playbooks
- **Incident Timeline** — Severity-ranked events and response actions
- **CVE Intelligence** — Prioritization and remediation
- **MCP Tool Gateway** — Security tool invocation
- **Agent Console & AI Assistant** — CLI orchestration and natural-language queries
- **Dynamic Risk Engine** — Risk score, GPU, and inference metrics

## Quick Start

```bash
git clone https://github.com/xrym135/nebula-sentinel.git
cd nebula-sentinel
npm install
npm run dev
```

http://localhost:3000
