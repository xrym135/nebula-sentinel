## [0.8.2] - 2026-05-21

### Added

- SOC main console with enterprise layout
- Attack Graph with selectable kill-chain stages
- Multi-Agent Workflow panel (Threat, CVE, Forensics, Response)
- MCP Tool Gateway tab with invocable security tools
- AI Security Assistant chat drawer
- Agent Console terminal with command presets
- Incident Timeline with response action modal
- CVE Intelligence with remediation workflow
- Dynamic risk score, GPU utilization, inference token counters
- Live security log stream with pause/resume
- Incident report JSON export
- Workload isolation and parallel analysis actions

### Changed

- Early Access branding and production-oriented copy
- Modular `components/soc/` architecture
